# BeruTUT — инструкции для Claude

Интернет-магазин (пет-проект): backend `.NET 8` + frontend `React 18`, репозиторий `art-mrx/BeruTUT`, ветка `main`. Пользователь общается по-русски.

**Перед любой работой прочитай `docs/context/README.md` и файлы, на которые он ссылается** (обзор, архитектура, домен и API, состояние, грабли окружения). Особенно `docs/context/05-environment-and-gotchas.md` — там ошибки, которые уже стоили времени (секреты, блокировка DLL запущенным backend, длинные heredoc в Bash, поведение браузерных инструментов).

Главное в одном экране:
- После каждого коммита — `git push` в `main` без вопросов. **Без `Co-Authored-By: Claude`.** Force-push в `main` не выполнять — подготовить команду для пользователя.
- После каждой доработки обновлять `docs/PROGRESS.md`, `docs/DECISIONS.md`, `docs/context/04-state-and-backlog.md`.
- «Готово» = юнит-тесты + реальная проверка (HTTP по настоящей БД и/или в браузере, включая ширину 375px) + обновлённая документация.
- Секреты и пароли в git не кладём и чужие пароли не вводим. Деплой отложен пользователем.
- Запущенный backend пользователя блокирует сборку — просить `Ctrl+C`, а не пытаться убить процесс.
- Код и тексты API — английские, интерфейс и документация — русские, коммиты — английские и развёрнутые.
